# PHONE-FRIENDLY COMMANDS

After the first setup message, these short messages should usually be enough:

## Continue
`Continue from project state.`

## Work autonomously
`Continue the authorized KTA work autonomously until you reach a material owner-decision boundary or complete the current stage.`

## Get only decisions
`Show me only the material decisions that need my approval.`

## Ask for status
`Give me a phone-sized status: completed, current, blockers, decisions needed, next.`

## Force a checkpoint
`Checkpoint now. Update state, progress, next action, handoff, and git if available.`

## Resume after context loss
`Read CLAUDE.md and resume from PROJECT_STATE.json, PROGRESS.md, NEXT_ACTION.md, the latest handoff, and git history.`

## Prepare a portable handoff
`Create a portable handover ZIP containing the current authoritative state, registries, current work, latest handoff, and exact continuation prompt.`
