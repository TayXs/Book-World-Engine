# KTA PROJECT LANE MAP v0.1

| Lane | Ownership |
|---|---|
| 00 — KNOWLEDGE → ACTION HQ | Master control, roadmap, current state, cross-project decisions |
| 01 — USER, PROBLEM & PRODUCT THESIS | Target user, problem, value proposition, consumer philosophy, product boundaries |
| 02 — MISSION & DIAGNOSTIC ENGINE | Goal intake, diagnostics, Task Maps, Mission Planner, personalization before advice; the first ActionExperiment and check-in interface (KTA-005) |
| 03 — RESEARCH, EVIDENCE & TRUST | Sources, evidence objects, research method, freshness, uncertainty, Trust Layer |
| 04 — EXPLANATION & EXPERIENCE ENGINE | Text, audio, visuals, learning sequence, comprehension, delivery interface |
| 05 — ACTION, FEEDBACK & OUTCOMES | ActionExperiments, check-ins, outcomes, adaptation logic, intervention intelligence; steward of the Lane 02 experiment/feedback specs and owner of ongoing and cross-user adaptation (KTA-005) |
| 06 — PRODUCT, SOFTWARE & DATA | UI, backend, APIs, database, privacy, infrastructure, model orchestration |
| 07 — PILOTS, BUSINESS & DISTRIBUTION | User testing, metrics, pricing, monetization, distribution, PMF |
| 08 — PRODUCT LAB & CHANGE REGISTRY | Proposed changes, experiments, pivots, parked/rejected ideas, change control |
| ARCHIVE | Historical and superseded material only |

## Rule
A discussion does not become product truth automatically. Any material proposal must be classified and reconciled through the governance system.
