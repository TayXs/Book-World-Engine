Watch Worth It

Everything on this page is optional. With no keys at all the extension still reads the transcript, pulls out the claims worth checking, and reads the channel signals off the watch page — it just cannot look anything up.

Free tier

Connect YouTube optional

Signs in with Google and asks for one read-only scope, youtube.readonly, so channel statistics can use your own free quota instead of an API key. It is never used for transcripts or for looking claims up — those are unauthenticated by design — and skipping this changes nothing else.

Not connected

Disconnecting forgets the token here. To revoke the grant itself, visit Google account permissions.

AI upgrade optional

Replaces the regex claim-extraction with one model call per video that also reasons about whether each claim is still current, using the provider's own web search. The fact-check lookup and the score are unchanged. Your key is stored locally and sent only to the provider you pick.

Cache

Results are kept per video in local storage for seven days.
