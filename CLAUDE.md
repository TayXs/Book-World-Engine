# Repository guide

This repository holds two independent projects:

| Folder | Project | Start here |
|---|---|---|
| `KTA/` | **Knowledge → Action (KTA)**: product definition and Mission Generation Engine work | `KTA/CLAUDE.md` |
| repo root (`truthcast/`, `web/`, `tests/`) | **Truthcast**: fact-checked digests of videos and podcasts | `README.md` |

For any KTA request, including "resume KTA", "continue from project state" or "checkpoint", read `KTA/CLAUDE.md` first and follow its startup procedure. Treat `KTA/` as the project root: every path in the KTA files is relative to it.

Do not mix changes between the two projects in one commit.
